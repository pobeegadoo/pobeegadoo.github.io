# Cybersecurity Portfolio & CV Website

A personal portfolio and CV website showcasing my professional experience,
cybersecurity background, technical skills, projects, achievements, and
current goals.

The website is designed with a modern cybersecurity-inspired interface
featuring a dark theme, neon elements, animations, and an interactive
timeline.

--

## 📌 About

This website serves as my online CV and professional portfolio.

It provides an overview of:

- Professional experience
- Education
- Cybersecurity skills
- Certifications
- Projects
- Research and publications
- Awards and achievements
- Current professional goals
- Contact information
